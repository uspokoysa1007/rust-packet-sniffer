# rust-packet-sniffer

Сетевой сниффер пакетов IPv4 на чистом Rust для Windows (через WinSock2 Raw Sockets).

## Возможности
- Захват сырых сетевых пакетов на сокетах (`SOCK_RAW` / `IPPROTO_IP`).
- Декодирование IPv4 заголовка:
  - Версия протокола, IHL, общий размер пакета (Total Length), TTL.
  - Определение протокола транспортного уровня: **TCP, UDP, ICMP, IGMP**.
  - Исходный и целевой IP-адреса.
- Декодирование TCP заголовков:
  - Порт источника и назначения, Sequence/Ack номера.
  - Флаги: `SYN, ACK, FIN, RST, PSH, URG`.
- Декодирование UDP заголовков (Порты и размер полезной нагрузки).
- Hex-дамп первых байт пейлоада.
- Встроенный безопасный режим тестирования (если запущен без прав администратора, выводит подробное разъяснение и переключается на генерацию и инспекцию локальных тестовых пакетов).

## Сборка
```bash
rustc -O src/main.rs -o releases/rust-packet-sniffer.exe -l ws2_32
```

## Использование
```bash
# Запуск от имени Администратора для полного захвата входящего трафика
./releases/rust-packet-sniffer.exe
```
